# 宅建2026 ノエルとルナの学習室

図・キャラクター・短い用語説明で学ぶ、個人用の宅建学習サイト。
50講義、演習200問、模試3回各50問／120分、暗記カード350枚。
対象は2026年10月18日の試験、法令基準は2026年4月1日、資料確認は2026年10月8日。

## 公開する

GitHub Pages用の静的サイトです。`docs/` に教材・アイコン・オフライン保存機能が入っています。
公開するのは教材だけです。ユーザーの解答、メモ、進捗はブラウザー内に保存し、サーバーへのアップロードを行いません。

1. このフォルダーの中身を、GitHubリポジトリの `main` ブランチへ登録します。
2. リポジトリの **Settings → Pages → Source** で **GitHub Actions** を選びます。
3. **Actions → Publish study room → Run workflow** を実行します。
4. 公開に成功したら **Settings → Pages** に表示されるURLを開きます。

GitHub Freeでは公開リポジトリで利用できます。リポジトリを非公開にできるプランでも、Pagesのサイト公開範囲は別なので、通常の公開教材として使ってください。公開準備ファイルに個人の学習記録は含まれていません。JSONバックアップをリポジトリへ追加しないでください。

別の方法として、Sourceを **Deploy from a branch**、ブランチを **main**、フォルダーを **/docs** にしても同じ教材を公開できます。

## スマホで学ぶ

公開URLをSafariやChromeで開きます。上部の「ホーム画面に追加・使い方」を押すと案内が出ます。
初回は通信がある場所で開き、「教材を端末に保存済み」を確認してください。その後は通信が切れても講義・演習を開けます。公式リンクや更新には通信が必要です。

iPhoneはSafariの共有メニューから「ホーム画面に追加」。AndroidはChromeのメニューからホーム画面追加／インストールができます。端末・ブラウザーごとの対応状況によって操作名は異なります。

## 前の記録を引き継ぐ

PCの旧版で「記録・設定」→「JSONバックアップを保存」。JSONファイルをスマホへ送り、公開サイト側の「記録・設定」で選んで復元します。ホーム画面に追加する場合は追加後にそのアイコンから開いて復元してください。自動同期はありません。

古いローカルHTMLと公開サイトは保存領域が異なるため、記録は自動では移りません。データ形式・問題IDは同じです。サイトを同じURLで更新した場合は、そのブラウザー内の進捗を引き続き利用できます。

サイトデータの削除、端末容量不足などでオフライン教材や記録が失われる場合があります。JSONバックアップを定期的に保存してください。端末内の記録に個人メモが含まれます。

## 更新

`docs/index.html` などを変更したら、`docs/sw.js` のキャッシュ版も更新してください。
版を変えることで更新時に新しい教材を保存します。キャッシュはこのサイトの範囲だけを整理し、localStorageの学習記録は消しません。自動再読み込みを行わず、更新時は「更新版を開く」ボタンを表示します。

本教材は理解確認用のオリジナルです。全選択肢に根拠を付けていますが、本試験と同一の難易度や合格を保証しません。公式過去問も併用してください。
